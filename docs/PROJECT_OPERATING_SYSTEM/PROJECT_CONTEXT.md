# Engineering Responsibilities

The Project Operating System is responsible for:

Maintaining project continuity.

Generating deterministic documentation.

Maintaining repository inventory.

Producing dependency maps.

Generating project snapshots.

Recording testing history.

Tracking sprint progress.

Maintaining project metadata.

Providing engineering context for future development.

The Project Operating System is not responsible for implementing business
features of the Recruitment Intelligence Platform.

---

# Maintenance Rules

This document is generated from machine-readable project state.

Manual edits are discouraged because they will be replaced during regeneration.

Governance documents remain exempt from automatic generation.

Generation shall preserve deterministic ordering and repository consistency.

Automation shall not modify application source code outside its defined scope.

---

# Future Evolution

Future enhancements to the Project Operating System shall:

Preserve backward compatibility.

Avoid architectural drift.

Maintain deterministic execution.

Respect frozen repository architecture.

Continue using machine-readable project state as the single source of truth.

Exclude governance documents from automatic regeneration.
